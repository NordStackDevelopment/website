## Why I made it

A GitHub profile is often the first thing people see. It should say who NordStack is at a glance: a developer and a
photographer.

## How it works

GitHub shows a README on your profile when it sits in a public repository with the same name as your account. The
banner at the top is an SVG built by a small Python script from the official logo and colours, framed like a camera
viewfinder with a terminal prompt in one corner.

## What I learned

SVG is enough for a lot: the banner is animated, sharp at any size, and about 100 KB.
